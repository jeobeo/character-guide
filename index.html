The plan

Joe rigs the stylized base body (BodyBaseMesh_01.fbx) in AccuRIG. That skeleton, Scrappy_Rig, becomes the one skeleton for every body and item. Alex weights bodies and clothes to it; masks and hats are plain meshes on a head socket. In Unity, each character loads and attaches only the pieces it wears, and animation, IK and gameplay stay untouched.

Order: J1 → A1–A2 → A9 (rig and body) → J2–J3, which gets the new rig playable. After that, Alex's A3–A8 and Joe's J4–J7 run side by side.

Decisions

AreaDecisionWhy
RigFresh AccuRIG rig on the base body; its A-pose is the rest pose. Frozen once J3 is done.The old rig was fitted to the clothed mesh and cut down to 62 bones. The clothes were modelled on this A-pose body, and A-pose deforms shoulders better. Unity handles it with Enforce T-Pose.
BonesAccuRIG's CC_Base_* names; keep the arm twist bones; remove helper, toe, breast and face bones.Twist bones stop wrists pinching when holding tools, driven by FinalIK's TwistRelaxer. Helper bones need drivers Unity doesn't have.

Masks & hatsPlain meshes on a head socket; the team decides the mask.They're the main customisation and there will be many. No weights to paint, cheapest to draw.
SkinOne whole body. Covered regions collapse in the shader; skin tone is a tint.Any outfit works on any body, and the body stays opaque and cheap.
LoadingItem prefabs load through Addressables only when worn or previewed. Outfits change in the lobby, where all loading happens.Direct references would load every item into memory at startup. Nothing loads mid-fight, and dedicated servers load none.
RegisteringOne editor command makes the prefab, item asset and id for every exported FBX.Hundreds of items by hand invites mistakes like duplicate ids.
SkinningGPU (Batched) mesh deformation.The project skins on the CPU today, which grows with every piece and player.
Not doingOne FBX with every item toggled on and off; UMA-style frameworks; deleting skin per outfit.Every character would carry every item, or they fight the existing rig and prefab.

Rig & body

Blender 3.6 or newer; menu paths below are the same in 3.6 and 4.x. The master file is ArtSource/Characters/Scrappy/Scrappy_Master.blend, next to Assets/, never inside it. Save before running any script.

Joe

J1 · Rig the base body in AccuRIG

  1. Load the body. Open AccuRIG and import BodyBaseMesh_01.fbx (one mesh, no skeleton, A-pose, about 26k triangles). If asked about orientation, make it face the front view and stand on the ground.

  2. Place the body markers, checking each in front and side view.

    • Markers go at the centre of each joint: middle of the wrist, elbow slightly behind the arm's centre line, knee slightly in front of the leg's.
    • Shoulders and wrists matter most: they decide how the arms and twist bones deform. Keep both sides symmetrical.

  3. Rig the hands with all five fingers; each finger marker on its knuckle.

  4. Test with AccuRIG's pose and motion preview. If shoulders cave in, elbows or knees collapse, or wrists twist badly, move that marker and rig again. That's much cheaper than fixing weights later.

  5. Export as FBX for Blender: mesh and skeleton, no animation, and keep the original A-pose if a pose option is offered.

  6. Hand over. Save it as ArtSource/Characters/Scrappy/Source/Body_M_01_AccuRIG.fbx, keep the AccuRIG project for re-rigging, and tell Alex it's ready for A1.

A1 · Clean the rig in Blender

  1. Create the master file. File › New › General, delete the cube, camera and light. Scene Properties › Units: Metric, Unit Scale 1.0, Length Meters. Save as ArtSource/Characters/Scrappy/Scrappy_Master.blend.

  2. Import the rigged body. File › Import › FBX, Body_M_01_AccuRIG.fbx. In the import panel, under Armature, tick Automatic Bone Orientation; leave the rest as default.

  3. Apply transforms. In Object Mode click the armature, Shift-click the body, Ctrl A › All Transforms. Check with N › Item: location 0, rotation 0, scale 1 on both, and the body hasn't moved.

  4. Rename in the Outliner (double-click): the armature object to Scrappy_Rig (the export finds it by this name), the body to Body_M_01. Don't rename bones.

  5. Collections. Outliner › right-click › New Collection: Rig, Bodies, _Reference. Move the rig into Rig and the body into Bodies (M). The export ignores _Reference.

  6. Know which bones stay. Expand Scrappy_Rig in the Outliner. Names can vary slightly between AccuRIG versions; follow the rule.

    • Keep: the root, CC_Base_Hip, Pelvis, Waist, Spine01, Spine02, NeckTwist01/02, Head, Clavicle, Upperarm, Forearm, Hand, all fingers, Thigh, Calf, Foot, ToeBase, and the arm twist bones UpperarmTwist01/02, ForearmTwist01/02 (both sides).
    • Remove: every ShareBone; the separate toes (BigToe1 … PinkyToe1); ThighTwist, CalfTwist; Breast, RibsTwist; face bones (FacialBone, JawRoot, UpperJaw, Teeth, Tongue, L/R_Eye).

  7. Remove them without losing weights. The script moves each removed bone's weights into its nearest kept parent, then deletes the bone.

    • Download the script (button below) and save it in ArtSource/Tools/.
    • Save the .blend. Click the Scripting tab at the top of Blender. In the Text Editor: Text › Open, pick merge_removed_bones.py, then click Run Script (▶) in the editor's header.
    • Window › Toggle System Console lists every bone it removed. If the list looks wrong, File › Revert.
    • By hand instead, per bone: Vertex Weight Mix modifier on the body (A = kept parent, B = removed bone, Vertex Set All, Mix Mode Add), moved above the Armature modifier and applied; delete that vertex group; in the rig's Edit Mode select the bone, X › Delete Bones.

    Checked against Blender 3.6 and 4.x

    View the script 
    """Moves the weights of unwanted AccuRIG bones into their nearest kept parent, then deletes those bones."""
import re
import bpy

RIG, BODY = "Scrappy_Rig", "Body_M_01"
REMOVE = re.compile(r"ShareBone|Toe1$|ThighTwist|CalfTwist|Breast|RibsTwist|FacialBone|Jaw|Teeth|Tongue|_Eye$")

rig, body = bpy.data.objects[RIG], bpy.data.objects[BODY]
bones = rig.data.bones
doomed = [b.name for b in bones if REMOVE.search(b.name)]


def keeper(name):
    parent = bones[name].parent
    while parent and parent.name in doomed:
        parent = parent.parent
    return parent.name


groups = body.vertex_groups
for name in doomed:
    source = groups.get(name)
    if source is None:
        continue
    target = groups.get(keeper(name)) or groups.new(name=keeper(name))
    weights = [(v.index, g.weight) for v in body.data.vertices for g in v.groups
               if g.group == source.index and g.weight > 0]
    for index, weight in weights:
        target.add([index], weight, "ADD")
    groups.remove(source)

bpy.ops.object.mode_set(mode="OBJECT")
bpy.context.view_layer.objects.active = rig
bpy.ops.object.mode_set(mode="EDIT")
for name in doomed:
    edit_bone = rig.data.edit_bones.get(name)
    if edit_bone:
        rig.data.edit_bones.remove(edit_bone)
bpy.ops.object.mode_set(mode="OBJECT")
print("Removed %d bones: %s" % (len(doomed), ", ".join(doomed)))

  8. Check the Armature modifier. Body_M_01 › Modifier Properties: one Armature modifier with Object = Scrappy_Rig. If missing, Add Modifier › Deform › Armature and set it.

  9. Clear any pose and save. Rig in Pose Mode, A, then Alt R, Alt G, Alt S. This A-pose is the rest pose for everything from now on.

A2 · Body weights

  1. Set up weight painting. Put the rig in Pose Mode, back to Object Mode, click Body_M_01, Shift-click the rig (body stays active), switch to Weight Paint. Ctrl-click a bone to select it and R to rotate it. Turn on X mirror in the header and Tool › Options › Auto Normalize.

  2. Pose-test one at a time, resetting with Alt R between:

    • Arms up, forward and crossed: shoulders and armpits.
    • Elbows and knees at 90°: no collapse or sharp creases.
    • Spine twisted 45° and bent forward; thigh raised forward; head turned and tilted.

  3. Fix what breaks with the Draw brush (Add/Subtract) and the Blur brush on the bones involved: low strength, several passes.

  4. Check wrist twist by hand (Blender doesn't drive twist bones): roll Hand 90° around its length, ForearmTwist02 about half as much, ForearmTwist01 about a quarter. The forearm should twist evenly, not pinch at the wrist.

  5. Finish from the Weights menu: Smooth where transitions look harsh (All Groups, factor 0.5); Limit Total 4 (All Groups); Normalize All (Lock Active off); Clean 0.01. Clear the pose and save.

A3 · Clothes into item files

Measured from the files: the clothed Scrappy's head, torso and legs already match the base body. Only the arms differ, because the old rig put them in a T-pose.

  1. Get the clothes. If you still have them from before the old AccuRIG pass (already A-pose), File › Append them into the master's _Reference and skip to step 4. Otherwise import Assets/Meshes/CM_Prefab_01/CM_Scrappy.fbx into _Reference and rename its armature Old_Skeleton.

  2. Pose the old arms onto the body. Hide Scrappy_Rig; Old_Skeleton in Pose Mode.

    • Rotate Left_Shoulder, Left_UpperArm, Left_LowerArm, Left_Hand (and fingers) until the clothed left hand and sleeve sit on Body_M_01's arm. The clothed hands are the base body's hands, so aim for an exact match; X-ray (Alt Z) helps.
    • Mirror: select the left arm bones, Ctrl C, select the right ones, Shift Ctrl V (Paste Pose Flipped).

  3. Bake the pose. On Clothing.002, Armature modifier dropdown › Apply. Delete Old_Skeleton, then Ctrl A › All Transforms on the clothing.

  4. Split. Edit Mode, P › By Material; delete the piece with the Body_A material (Body_M_01 replaces it). In each remaining set, hover a garment, L (Shift L for more parts), P › Selection. Name each with the naming pattern (Torso_Shirt01_U, Mask_Skull01_U, Backpack_Scrap01_U).

  5. Make the item template, once.

    • File › New › General, delete the defaults, same units as the master.
    • New collection _Reference, make it active, File › Link › Scrappy_Master.blend › Object › Scrappy_Rig and Body_M_01. Linked means read-only and always in step with the master.
    • Empty collections: Torso, Legs, Feet, Hands, Mask, Headwear, Backpack, Accessories.
    • Save as ArtSource/Characters/Scrappy/Items/_ItemTemplate.blend.

  6. One file per item. For each item:

    • Open the template and immediately Save As Items/<Slot>/<Slot>_<Name><NN>.blend (e.g. Items/Torso/Torso_Shirt01.blend).
    • File › Append › Scrappy_Master.blend › Object › the item; M it into its slot collection. All fits of one item (_M, _F, _U) share a file.
    • Items that will get swing bones (backpacks, scarves, hems): Append Scrappy_Rig instead of linking it, so the file has an editable copy (A7).
    • Once saved, delete the item from the master's _Reference.

A4 · Weight every clothing piece from the body

  1. Install Robust Weight Transfer once: a free add-on that gives sensible weights where cloth sits away from the body.

    • Download its release .zip from its GitHub page (don't unzip it).
    • Blender 3.6: Edit › Preferences › Add-ons › Install…, pick the zip, then tick its checkbox. Blender 4.2+: Edit › Preferences › Get Extensions › search for it, or the ▾ menu › Install from Disk.
    • If your Blender version won't take it, use the built-in fallback in step 4; it's slower to clean up but gives the same result.

  2. Open the item's file. To pose the linked rig for testing: Outliner › right-click it › Library Override › Make › Selected (local to this file).

  3. Clear old weights. Object Data Properties › Vertex Groups › dropdown › Delete All Groups. Modifier Properties: remove old Armature modifiers, then Add Modifier › Deform › Armature, Object = Scrappy_Rig.

  4. Transfer. Click Body_M_01, Shift-click the piece (piece active), run the add-on from its N sidebar tab with default settings.

    • Built-in fallback: Data Transfer modifier on the piece, Source Body_M_01, Vertex Data › Vertex Groups, Mapping Nearest Face Interpolated, Generate Data Layers, move it above the Armature modifier, Apply.

  5. Pose-test with the body visible (A2's poses). Where the body pokes through outside the cloth, blur the cloth's weights toward the body's underneath; don't move the cloth. Skin fully under the cloth is hidden in-game.

  6. Rigid bits (buckles, plates): Edit Mode, L the part, Ctrl G › Remove from All, pick one bone's vertex group, Weight 1.0, Assign.

  7. Finish: Weights › Limit Total 4 (All Groups), Normalize All. Clear the pose and save.

A6 · Masks and hats

  1. Model in place in the item file's Mask (or Headwear) collection, on the linked Body_M_01's head in rest pose, 2–5 mm off the skin.

  2. Keep it a plain mesh: no Armature modifier, no vertex groups, no parent. Mirror or Subdivision modifiers are fine (the export applies them). Its position on the head is its attach point, so don't move it afterwards.

  3. Budget: up to 1.5k triangles (Overlays › Statistics); one UV set.

  4. Team colour (optional): Opacity channel white where the team colour shows, black elsewhere.

  5. Fit every body: once Body_F_01 exists, check the mask on it too; the whole team shares one mask.

    """Exports the pieces in one .blend for Unity: the rig and bodies from Scrappy_Master.blend, items from item files.

blender -b <file.blend> --python export_scrappy_parts.py -- <unity project folder> [name filter]
"""
import os
import sys
import bpy

ARMATURE = "Scrappy_Rig"                     # armature object name
MASTER = "Scrappy_Master.blend"              # the only file allowed to export the rig
OUT = "Assets/Art/Characters/Scrappy"
FOLDERS = {                                  # Blender collection -> Unity folder
    "Bodies": "Bodies",
    "Torso": "Wardrobe/Torso", "Legs": "Wardrobe/Legs", "Feet": "Wardrobe/Feet",
    "Hands": "Wardrobe/Hands", "Mask": "Wardrobe/Mask", "Headwear": "Wardrobe/Headwear",
    "Backpack": "Wardrobe/Backpack", "Accessories": "Wardrobe/Accessories",
}
SOCKET = {"Mask", "Headwear"}                # plain meshes on Socket_Head, exported in place
REGIONS = ["Head", "Face", "Neck", "Chest", "Stomach", "UpperArms",
           "Forearms", "Hands", "Hips", "Thighs", "Shins", "Feet"]

args = sys.argv[sys.argv.index("--") + 1:]
project = os.path.abspath(args[0])
name_filter = args[1] if len(args) > 1 else ""
# The rig in this file's scene: the master's own, a library override, or an item's appended copy.
armature = next(o for o in bpy.context.view_layer.objects if o.type == "ARMATURE" and o.name == ARMATURE)


def bake_regions(obj):
    """Bodies: Region_* vertex groups -> second UV map 'Regions' (u = region index, one value per face)."""
    index_of = {g.index: REGIONS.index(g.name[7:]) for g in obj.vertex_groups
                if g.name.startswith("Region_") and g.name[7:] in REGIONS}
    if not index_of:
        return
    mesh = obj.data
    uv = mesh.uv_layers.get("Regions") or mesh.uv_layers.new(name="Regions")
    region_of = {}
    for v in mesh.vertices:
        for g in v.groups:
            if g.group in index_of and g.weight > 0.5:
                region_of[v.index] = index_of[g.group]
    for poly in mesh.polygons:
        votes = {}
        for vi in poly.vertices:
            if vi in region_of:
                votes[region_of[vi]] = votes.get(region_of[vi], 0) + 1
        region = max(votes, key=votes.get) if votes else 0
        for li in poly.loop_indices:
            uv.data[li].uv = (region + 0.5, 0.0)


def export(objects, path):
    bpy.ops.object.select_all(action="DESELECT")
    for o in objects:
        o.hide_set(False)
        o.select_set(True)
    bpy.context.view_layer.objects.active = objects[0]
    os.makedirs(os.path.dirname(path), exist_ok=True)
    bpy.ops.export_scene.fbx(
        filepath=path, use_selection=True, object_types={"ARMATURE", "MESH"},
        apply_unit_scale=True, apply_scale_options="FBX_SCALE_UNITS",
        axis_forward="-Z", axis_up="Y",
        use_mesh_modifiers=True, mesh_smooth_type="FACE",
        add_leaf_bones=False, use_armature_deform_only=True,
        primary_bone_axis="Y", secondary_bone_axis="X",
        bake_anim=False, path_mode="STRIP", embed_textures=False)
    print("Exported", path)


if os.path.basename(bpy.data.filepath) == MASTER and not name_filter:
    export([armature], os.path.join(project, OUT, "Rig", "SK_Scrappy_Rig.fbx"))

for collection, folder in FOLDERS.items():
    coll = bpy.data.collections.get(collection)
    if coll is None or coll.library:         # linked collections belong to another file's export
        continue
    for obj in coll.all_objects:
        if obj.type != "MESH" or obj.name.startswith("_") or obj.library or name_filter not in obj.name:
            continue
        skinned = any(m.type == "ARMATURE" for m in obj.modifiers)
        if collection in SOCKET:
            if skinned:
                print("SKIPPED (masks and hats must not be skinned):", obj.name)
                continue
            export([obj], os.path.join(project, OUT, folder, "SM_" + obj.name + ".fbx"))
            continue
        if not skinned:
            print("SKIPPED (not skinned to the rig):", obj.name)
            continue
        if collection == "Bodies":
            bake_regions(obj)
        export([obj, armature], os.path.join(project, OUT, folder, "SK_" + obj.name + ".fbx"))

  2. Save the .blend and make sure its collections aren't excluded in the Outliner (the tick box).

  3. Export: in File Explorer, drag the .blend onto Export to Unity.bat. Blender doesn't need to be open.

    • An item: drag its file from Items/<Slot>/.
    • Rig and bodies: drag Scrappy_Master.blend.
    • Several at once: select them all and drag them together. To redo every item, search *.blend inside Items/, select all, drag.

  4. Read the window that opens. Each piece prints "Exported …". Fix anything marked SKIPPED (a mask still skinned, or a clothing piece with no Armature modifier) and drag the file on again. Press any key to close.

  5. Hand over: tell Joe what changed and which body regions each new item covers.

    • Create › Group › Packed Assets named Wardrobe; in its Inspector, Bundle Mode: Pack Separately (wearing one mask loads only that mask). Drag the Prefabs folder into it. Do the same with Icons in a group WardrobeIcons.

  4. Import rules: create Assets/Scripts/Editor/ScrappyCharacterImportRules.cs (joins Scrapsized.Editor) with the code below, then Ctrl R. Every later import gets the right settings automatically.

    ScrappyCharacterImportRules.cs 
    using System.IO;
using System.Linq;
using UnityEditor;
using UnityEngine;

namespace Scrapsized.Editor
{
    /// <summary>
    /// First-import settings for Scrappy character content, chosen by folder. The rig owns the avatar; every skinned
    /// piece copies it (which also flags a renamed bone). Masks and hats are plain meshes.
    /// </summary>
    sealed class ScrappyCharacterImportRules : AssetPostprocessor
    {
        const string Root = "Assets/Art/Characters/Scrappy/";
        const string Rig = Root + "Rig/SK_Scrappy_Rig.fbx";

        void OnPreprocessModel()
        {
            if (!assetPath.StartsWith(Root)) return;
            var importer = (ModelImporter)assetImporter;
            if (!importer.importSettingsMissing) return; // only the first import; later tweaks stand

            string file = Path.GetFileName(assetPath);
            bool animation = assetPath.StartsWith(Root + "Animations/");

            importer.importAnimation = animation;
            importer.materialImportMode = ModelImporterMaterialImportMode.None; // materials live on the item prefab
            importer.generateSecondaryUV = false;                               // UV1 carries body regions
            importer.isReadable = false;

            if (file.StartsWith("SM_"))
            {

    WardrobeBuilder.cs: Tools › Scrapsized › Wardrobe › Build Items and Catalog 
    using System.Collections.Generic;
using System.IO;
using System.Linq;
using UnityEditor;
using UnityEngine;
using UnityEngine.AddressableAssets;

namespace Scrapsized.Editor
{
    /// <summary>
    /// Turns every exported wardrobe FBX into a prefab (with its M_<Item> material) and a WardrobeItem, hands out
    /// ids and rebuilds the catalog. Safe to run any time: it never overwrites a prefab or undoes edits to an item.
    /// </summary>
    static class WardrobeBuilder
    {
        const string Root = "Assets/Art/Characters/Scrappy/";
        const string CatalogPath = Root + "Items/WardrobeCatalog.asset";

        [MenuItem("Tools/Scrapsized/Wardrobe/Build Items and Catalog")]
        static void Build()
        {
            int newPrefabs = 0, newItems = 0;
            foreach (string guid in AssetDatabase.FindAssets("t:Model", new[] { Root + "Wardrobe" }))
            {
                string modelPath = AssetDatabase.GUIDToAssetPath(guid);
                string file = Path.GetFileNameWithoutExtension(modelPath);          // SK_Torso_Jacket01_M
                if (!file.StartsWith("SK_") && !file.StartsWith("SM_")) continue;
                string piece = file.Substring(3);                                   // Torso_Jacket01_M
                int cut = piece.LastIndexOf('_');
                if (cut < 0 || !System.Enum.TryParse(piece.Split('_')[0], out WardrobeSlot slot))
                {
                    Debug.LogWarning($"[Wardrobe] {file} doesn't follow <Slot>_<Name><NN>_<Fit>; skipped.");
                    continue;
                }
                string itemName = piece.Substring(0, cut), fit = piece.Substring(cut + 1);

                string prefabPath = $"{Root}Prefabs/{slot}/{piece}.prefab";
                if (AssetDatabase.LoadAssetAtPath<GameObject>(prefabPath) == null)
                {
                    Directory.CreateDirectory(Path.GetDirectoryName(prefabPath));
                    var instance = (GameObject)PrefabUtility.InstantiatePrefab(AssetDatabase.LoadAssetAtPath<GameObject>(modelPath));
                    var material = AssetDatabase.LoadAssetAtPath<Material>($"{Root}Materials/M_{itemName}.mat");
                    if (material != null)
                        foreach (var r in instance.GetComponentsInChildren<Renderer>(true))
                            r.sharedMaterials = Enumerable.Repeat(material, r.sharedMaterials.Length).ToArray();
                    else
                        Debug.LogWarning($"[Wardrobe] No M_{itemName}.mat yet; set the material on {prefabPath}.");
                    PrefabUtility.SaveAsPrefabAsset(instance, prefabPath);
                    Object.DestroyImmediate(instance);
                    newPrefabs++;
                }

                string itemPath = $"{Root}Items/{slot}/{itemName}.asset";
                var item = AssetDatabase.LoadAssetAtPath<WardrobeItem>(itemPath);
                if (item == null)
                {
                    Directory.CreateDirectory(Path.GetDirectoryName(itemPath));
                    item = ScriptableObject.CreateInstance<WardrobeItem>();
                    item.Slot = slot;
                    item.DisplayName = itemName.Substring(itemName.IndexOf('_') + 1);
                    item.Hides = DefaultHides(slot);
                    AssetDatabase.CreateAsset(item, itemPath);
                    newItems++;
                }
                if (!item.Variants.Any(v => v.FitTag == fit))
                {
                    item.Variants.Add(new WardrobeItem.Variant
                    {
                        FitTag = fit,
                        Prefab = new AssetReferenceGameObject(AssetDatabase.AssetPathToGUID(prefabPath)),
                    });
                    EditorUtility.SetDirty(item);
                }
            }

            RebuildCatalog();
            AssetDatabase.SaveAssets();
            Debug.Log($"[Wardrobe] {newPrefabs} new prefab(s), {newItems} new item(s). Catalog rebuilt.");
        }

        static void RebuildCatalog()
        {
            Directory.CreateDirectory(Root + "Items");
            var catalog = AssetDatabase.LoadAssetAtPath<WardrobeCatalog>(CatalogPath);
            if (catalog == null)
            {
                catalog = ScriptableObject.CreateInstance<WardrobeCatalog>();
                AssetDatabase.CreateAsset(catalog, CatalogPath);
            }

            var items = Load<WardrobeItem>();
            var taken = new HashSet<ushort>(catalog.RetiredIds);
            foreach (var item in items.Where(i => i.Id != 0))
                if (!taken.Add(item.Id)) Debug.LogError($"[Wardrobe] Duplicate id {item.Id} on {item.name}.", item);
            ushort next = (ushort)(taken.Count == 0 ? 1 : taken.Max() + 1);
            foreach (var item in items.Where(i => i.Id == 0))
            {
                item.Id = next++;
                EditorUtility.SetDirty(item);
            }

            catalog.Items = items.OrderBy(i => i.Id).ToList();
            catalog.Bodies = Load<BodyDefinition>().OrderBy(b => b.Id).ToList();
            EditorUtility.SetDirty(catalog);
        }

        static List<T> Load<T>() where T : Object =>
            AssetDatabase.FindAssets("t:" + typeof(T).Name)
                .Select(g => AssetDatabase.LoadAssetAtPath<T>(AssetDatabase.GUIDToAssetPath(g)))
                .Where(a => a != null).ToList();

        static BodyRegions DefaultHides(WardrobeSlot slot) => slot switch
        {
            WardrobeSlot.Torso => BodyRegions.Chest | BodyRegions.Stomach | BodyRegions.UpperArms,
            WardrobeSlot.Legs => BodyRegions.Hips | BodyRegions.Thighs | BodyRegions.Shins,
            WardrobeSlot.Feet => BodyRegions.Feet,
            WardrobeSlot.Hands => BodyRegions.Hands,
            WardrobeSlot.Mask => BodyRegions.Face,
            WardrobeSlot.Headwear => BodyRegions.Head,
            _ => BodyRegions.None,
        };
    }
}

    WardrobeLoader.cs: load on demand, unload when unused 
    using System.Collections.Generic;
using System.Threading.Tasks;
using UnityEngine;
using UnityEngine.AddressableAssets;
using UnityEngine.ResourceManagement.AsyncOperations;

/// <summary>Loads wardrobe prefabs on demand and unloads them when nothing uses them. Every Acquire needs a Release.</summary>
public static class WardrobeLoader
{
    sealed class Entry { public AsyncOperationHandle<GameObject> Handle; public int Users; }
    static readonly Dictionary<string, Entry> s_Loaded = new Dictionary<string, Entry>();

    // Domain reload is off in this project: forget the last play session's handles.
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]
    static void Reset() => s_Loaded.Clear();

    public static Task<GameObject> Acquire(AssetReferenceGameObject prefab)
    {
        if (!s_Loaded.TryGetValue(prefab.AssetGUID, out Entry entry))
        {
            entry = new Entry { Handle = Addressables.LoadAssetAsync<GameObject>(prefab) };
            s_Loaded[prefab.AssetGUID] = entry;
        }
        entry.Users++;
        return entry.Handle.Task;
    }

    public static void Release(AssetReferenceGameObject prefab)
    {
        if (!s_Loaded.TryGetValue(prefab.AssetGUID, out Entry entry) || --entry.Users > 0) return;
        Addressables.Release(entry.Handle);
        s_Loaded.Remove(prefab.AssetGUID);
    }
}
    SkeletonBinder.cs: attach a piece to the character's bones by name 
    using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// Moves a wardrobe piece onto the character's skeleton by bone name. Item bones the rig doesn't have (swing bones)
/// are re-homed under the character's bone that matches their original parent, keeping their local rest offset.
/// </summary>
public static class SkeletonBinder
{
    public static Dictionary<string, Transform> Index(Transform skeletonRoot)
    {
        var bones = new Dictionary<string, Transform>();
        foreach (var t in skeletonRoot.GetComponentsInChildren<Transform>(true)) bones[t.name] = t;
        return bones;
    }

    /// <summary>Returns the swing bones it moved onto the character, so they can be destroyed with the piece.</summary>
    public static List<Transform> Bind(SkinnedMeshRenderer piece, Dictionary<string, Transform> master)
    {
        var moved = new List<Transform>();
        Transform[] bones = piece.bones;
        for (int i = 0; i < bones.Length; i++)
        {
            Transform own = bones[i];
            if (own == null) continue;
            if (master.TryGetValue(own.name, out Transform shared)) { bones[i] = shared; continue; }

            // Swing bone. Only the top of each chain moves; its children come with it.
            if (own.parent != null && master.TryGetValue(own.parent.name, out Transform newParent))
            {
                own.SetParent(newParent, false);
                moved.Add(own);
            }
        }
        piece.bones = bones;
        if (piece.rootBone != null && master.TryGetValue(piece.rootBone.name, out Transform root))
            piece.rootBone = root;
        return moved;
    }
}

  1. Add SpringChain.cs and SpringCollider.cs next to the data types.

    SpringChain.cs, SpringCollider.cs 
    using UnityEngine;

/// <summary>
/// Verlet secondary motion for an item's swing bones (Backpack_Main, Backpack_Flap, strap links). One component
/// per item; bones are listed parents before children. Each bone starts from its rest pose under its already-solved
/// parent every frame, so animation stays in charge and this only adds lag, sway and bounce.
/// </summary>
[DefaultExecutionOrder(20000)] // after Animancer, FinalIK and socket followers (10000)
public sealed class SpringChain : MonoBehaviour
{
    [System.Serializable]
    public struct Bone
    {
        public Transform Transform;
        [Range(0f, 1f)] public float Stiffness;      // pull back towards the animated pose
        [Range(0f, 1f)] public float Damping;
    }

    public Bone[] Bones;                             // parents before children; _Tip bones are not listed
    public Vector3 Gravity = new Vector3(0f, -1.5f, 0f);
    public float Radius = 0.04f;
    public float MaxDistance = 30f;
    public SpringCollider[] Colliders;               // body proxies, set on equip
    public static Vector3 Wind;                      // set by the weather system

    Quaternion[] _rest;
    Vector3[] _localTip, _tip, _previous;

    void OnEnable()
    {
        int n = Bones.Length;
        _rest = new Quaternion[n]; _localTip = new Vector3[n]; _tip = new Vector3[n]; _previous = new Vector3[n];
        for (int i = 0; i < n; i++)
        {
            Transform bone = Bones[i].Transform;
            _rest[i] = bone.localRotation;
            _localTip[i] = TipOf(bone);
            _tip[i] = _previous[i] = bone.TransformPoint(_localTip[i]);
        }
    }

    // The bone's "_Tip" child gives the lever; otherwise its first child.
    static Vector3 TipOf(Transform bone)
    {
        foreach (Transform child in bone) if (child.name.EndsWith("_Tip")) return child.localPosition;
        return bone.childCount > 0 ? bone.GetChild(0).localPosition : Vector3.up * 0.1f;
    }

    void LateUpdate()
    {
        Camera view = Camera.main;
        bool near = view == null || (view.transform.position - transform.position).sqrMagnitude < MaxDistance * MaxDistance;
        float dt = Mathf.Min(Time.deltaTime, 1f / 30f);
        for (int i = 0; i < Bones.Length; i++)
        {
            Transform bone = Bones[i].Transform;
            bone.localRotation = _rest[i];                   // rest pose under the parent solved this frame
            Vector3 target = bone.TransformPoint(_localTip[i]);
            if (!near) { _tip[i] = _previous[i] = target; continue; }

            Vector3 next = _tip[i] + (_tip[i] - _previous[i]) * (1f - Bones[i].Damping) + (Gravity + Wind) * (dt * dt);
            next += (target - next) * Bones[i].Stiffness;
            foreach (SpringCollider c in Colliders) if (c != null) next = c.PushOut(next, Radius);
            float length = (target - bone.position).magnitude;
            next = bone.position + (next - bone.position).normalized * length;

            _previous[i] = _tip[i];
            _tip[i] = next;
            bone.rotation = Quaternion.FromToRotation(target - bone.position, next - bone.position) * bone.rotation;
        }
    }
}

/// <summary>A body proxy for springs. Not a physics collider: the character controller and raycasts never see it.</summary>
public sealed class SpringCollider : MonoBehaviour
{
    public float Radius = 0.12f;

    public Vector3 PushOut(Vector3 point, float extra)
    {
        Vector3 offset = point - transform.position;
        float r = Radius + extra;
        return offset.sqrMagnitude < r * r ? transform.position + offset.normalized * r : point;
    }
}
